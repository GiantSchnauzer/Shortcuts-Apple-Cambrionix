# Shortcuts - Apple Configurator & Cambrionix

These shortcuts use the following tools:

1. Apple Configurator `cfgutil`
2. Cambrionix API and shortcuts
3. Homebrew
4. Required Homebrew formulae:
   - jq
   - bash
   - imagemagick
   - capstone
   - libimobiledevice
   - libtool
   - autoconf
   - automake
   - pkg-config
   - libimobiledevice-glue
   - libirecovery
   - ipsw
